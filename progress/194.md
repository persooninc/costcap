# #194 OpenAI Realtime API over WebSocket

Status: done. The proxy has an `upgrade` handler for `/openai/v1/realtime` (`src/realtime.js` frame codec, Node built-ins only).
- The handshake goes through the same admission gate as HTTP before `101`. Other upgrade paths get `501 websocket_unsupported` and no latch, which fixes the freeze.
- Bytes are relayed unchanged. One receipt is written per `response.done` at the text/audio/image rates (accumulator reads `input_token_details`/`output_token_details`). The gate is re-checked after every receipt and closes with `1008` on a hit. Kill closes idle sessions within 1 s.
- Honest unknowns: `stream_incomplete`, `modality_unpriced`, `transcription_unpriced`. Rejected handshakes are $0.
- Pricing: gpt-realtime, -2.1, -2.1-mini (text/audio/image) and gpt-realtime-mini (text only, per issue scope; the OpenAI page also lists audio for it). Table 2026-11-16.7, digest regenerated.
- `wrap` exports `COSTCAP_OPENAI_REALTIME_URL`. README has a "OpenAI Realtime API" section.
- Tests: test/proxy-realtime.test.js plus fixtures/realtime-upstream.js; extended modality-pricing, proxy-regression, kill and cli tests.
