# #207 Budget-triggered model downgrade

- `wrap --downgrade FROM=TO[,FROM=TO] [--downgrade-at F]` (default 0.8): past F of the first run/hour/day/month cap (local, `--policy` agent/team, enrolled fleet agent), only the JSON `model` is rewritten on openai/anthropic/openrouter/custom routes, before the allowlist, unknown-models, preflight, tag caps and cache key. Unsupported routes pass through with receipt `downgrade: "unsupported_route"`. Unpriced TO exits 2 at start.
- Receipt `model: TO, requested_model: FROM, downgrade: {scope, fraction}`; header `x-costcap-model-downgraded`; one `model_downgrade` ledger + stderr line per scope and period; run summary / `costcap runs` show `downgraded_calls`. Hard stop at 100% unchanged.
- Fleet: `downgrade: {at, map}` on agent policy (validated, local only adds/tightens, dashboard agent card fields, audited).
- Code: `src/downgrade.js`, `src/proxy.js`, `src/cli.js`, `src/hosted/policy.js`, `src/hosted/server.js`, `src/hosted/ui.js`, `src/run-summary.js`. Tests: `test/model-downgrade.test.js`. README "Model downgrade".
