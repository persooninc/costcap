# #170 wrap stamps run_id without --agent

Landed in 7f627c3. `wrap` stamps `run_id` (`--run-id` or a generated UUID) on every receipt with or without `--agent`. The `costcap runs` summary uses the same id, so `check --run-id` and hosted run alerts (#168) find wrapper receipts. Tests: `test/wrap-run-id.test.js` (AC1-6, including `summarizeRuns` grouping). `--policy` still needs `--agent`.
